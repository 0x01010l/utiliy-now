Use this checklist before publishing or refreshing a product detail page. For an automated pass, run the [product page auditor](/product-page-auditor/).

## Technical & indexation

1. Returns HTTP 200
2. Canonical URL points to the preferred version
3. Not blocked by robots.txt for Googlebot
4. Loads critical product content in HTML (not JS-only)

## On-page SEO

5. Unique title tag (~50–60 characters, descriptive)
6. Meta description matches search intent
7. One clear H1 with the product name
8. Subheadings for specs, shipping, FAQs
9. Enough unique copy (not factory duplicate used by 20 stores)

## Structured data

10. Valid Product JSON-LD
11. Offer with price, currency, availability
12. Brand, SKU, or GTIN where applicable
13. Schema matches visible price and stock status

## Product information

14. Dimensions and weight (when category expects them)
15. Materials / compatibility / variant clarity
16. Warranty and returns policy linked or summarized
17. Shipping expectations stated

## Images

18. At least 2 gallery images
19. Descriptive alt text on primary images
20. Images support key claims (not decorative only)

## AI shopping & conversion

21. Who the product is for is obvious in first screen
22. Benefits, not only feature bullets
23. Trust signals (reviews, guarantees) visible if claimed
24. No conflicting prices between schema, cart, and visible page
