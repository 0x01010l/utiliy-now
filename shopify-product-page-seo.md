## Shopify-specific issues we detect

When Utiliy detects Shopify, the audit notes platform patterns:

- **Theme SEO fields** — title and meta from admin vs overridden in theme
- **Duplicate H1** from product title + section headings
- **Variant URLs** without clean canonical handling
- **App-injected schema** conflicting with theme JSON-LD
- **Thin default descriptions** from dropshipping templates

## What to fix first on Shopify

1. Unique title: `Product name + key attribute + brand` (not 120 characters of keyword stuffing)
2. Meta description written for click intent, not factory copy
3. Product schema via Shopify or valid JSON-LD with correct Offer
4. Alt text on every gallery image with human-readable descriptions
5. FAQs or specs block for long-tail queries the product should win

Run the auditor on your live `myshopify.com` or custom domain product URL.
