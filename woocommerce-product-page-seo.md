## WooCommerce SEO is often plugin-shaped

WooCommerce stores frequently stack SEO plugins, schema plugins, and page builders. Utiliy flags:

- Multiple SEO plugins outputting conflicting meta tags
- Product schema from Yoast, RankMath, or WooCommerce core — and duplicates
- Short descriptions empty while long description is a page builder canvas
- Category-style titles on product URLs

## WooCommerce checklist (beyond plugins)

| Area | Action |
|------|--------|
| Permalinks | `/product/` slugs clean and stable |
| Schema | Single Product JSON-LD with valid Offer |
| Images | Featured + gallery alts filled in media library |
| Attributes | Visible attributes for filters and long-tail queries |
| Reviews | Only add review schema if reviews are real and visible |
